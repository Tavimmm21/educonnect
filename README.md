# EduConnect — Frontend

Frontend demonstrativo de um portal acadêmico responsivo.

## Stack
- React + TypeScript
- Vite
- Material-UI (MUI) + Emotion
- Lucide React

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra a URL exibida pelo Vite.

## Funcionalidades demonstradas
- Dashboard acadêmico
- Consulta de notas
- Disciplinas com busca e progresso
- Matrícula com seleção e resumo
- Perfil editável
- Sidebar desktop + navegação inferior mobile
- Notificações
- Menus e toasts
- Microinterações e animações

Os dados são mockados e o frontend está pronto para ser conectado a uma API/backend.
